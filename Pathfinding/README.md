# Task 3 - Heuristic Graph Pathfinding Agent Search Engine

## Project Overview
This project implements a heuristic graph pathfinding system using Python and Google Colab.

The system helps virtual agents find paths from a starting point to a destination while avoiding obstacles in a grid maze.

## Algorithms Implemented
1. A* Search Algorithm
2. Dijkstra's Algorithm
3. Q-Learning

## Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Heapq

## Project Features
- Grid-based maze environment
- Obstacle detection
- Pathfinding using A* and Dijkstra
- Q-Learning agent training
- Low, Medium and High obstacle density testing
- Performance comparison
- Path visualization
- CSV result export

## Results
All tested algorithms successfully found a path to the goal.

The A* algorithm explored fewer nodes than Dijkstra in all three tested obstacle-density environments.

Q-Learning successfully learned a path of 28 steps in the medium-density maze.

The project successfully demonstrates different pathfinding and learning algorithms in a grid-based environment.
