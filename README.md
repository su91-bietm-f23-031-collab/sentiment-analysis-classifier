
# Intelligent Multi-Class NLP Sentiment Classifier

## Project Overview
This project uses Natural Language Processing (NLP) and Machine Learning to classify text into three sentiment categories: Negative, Neutral, and Positive.

## Dataset
Dataset: TweetEval Sentiment  
Training samples: 45,615  
Validation samples: 2,000  
Testing samples: 12,284  

## Technologies Used
- Python
- Scikit-learn
- NLTK
- Pandas
- Matplotlib
- TF-IDF Vectorization
- Logistic Regression

## Text Preprocessing
- Convert text to lowercase
- Remove URLs and mentions
- Remove English stop words
- Apply lemmatization

## Model Evaluation
Test Accuracy: 59.60%  
Test Macro F1-score: 56.78%  
Test Weighted F1-score: 58.57%

## Sentiment Classes
- 0: Negative
- 1: Neutral
- 2: Positive
