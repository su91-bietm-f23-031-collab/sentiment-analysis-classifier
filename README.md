# Multi-Class NLP Sentiment Classifier

## Project Overview
This project classifies text into three sentiment categories: Negative, Neutral, and Positive.

## Technologies Used
- Python
- Scikit-learn
- NLTK
- TF-IDF
- Logistic Regression

## Dataset
TweetEval Sentiment Dataset.

## Evaluation Results
- Test Accuracy: 59.60%
- Macro F1-Score: 56.78%
- Weighted F1-Score: 58.57%

## Project Files
The ZIP file contains the Python script, trained model, TF-IDF vectorizer, confusion matrix, and evaluation results.

## Purpose
This project was completed as part of an AI/NLP internship task
